# Preform API Test

## About

The purpose of this repo is to create a quick way to get the headless Preform
server from Formlabs running, setup the requirements for their python library,
and test that a small script can connect to the server. It additionally runs
python inside a container and 

The compose file was generated by referencing the
[guide](https://developer.formlabs.com/guides/preform-server-docker/) from
Fromlabs and translating the `docker run` command to compose syntax. In order to
enable a health check, the base formlabs/preform-server image is built using a
Dockerfile to add the curl utility.

## Setup

```
git clone https://github.com/FullTiltGroup/preform_api_test.git
cd preform_api_test
docker compose up
```

You should see a string of warnings as preform starts up and then the string
`Ready For Input` followed closely by `Container preform-server Healthy`.
The python script will then automatically fire and should print 
`PreForm <version> at http://preform-server:44388`
